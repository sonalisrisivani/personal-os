# Personal Career OS

Private, self-hostable career operating system built incrementally with Next.js, FastAPI, PostgreSQL, and n8n.

## Execution

The compact execution source of truth is [`docs/career-os-map.mmd`](docs/career-os-map.mmd). Read it before starting work, complete blocks in order, and update its status after validation. [`docs/plan.md`](docs/plan.md) contains the supporting design and scope.

Each completed map block is delivered as a focused commit. The first usable application slice will be the foundation and local deployment block.
